# サブスク管理アプリ 企画・要件定義書

## 1. 企画概要

### コアバリュー
登録したサブスクの月額を自動で合計し、「今月自分はいくら払っているか」を一目で把握できる、自分専用のサブスク管理アプリ。
各サブスクには「解約締切日」を持たせ、いつまでに動けば次回の請求を止められるかも管理できる。

### 想定ユーザー
自分専用(自分の管理に使う)

### 解決したい課題
月々の支払い合計を把握したい。加えて、「この日までに解約すればお金が発生しない」というキャンセル前提の支払い管理を行いたい。

---

## 2. MVP機能一覧

| 機能 | 対応するCRUD |
|---|---|
| サブスクを登録する | Create |
| 登録済み一覧を見る | Read |
| 月額合計を表示する(全体のみ) | Read(集計) |
| 内容を編集する | Update |
| 解約したものを削除する(確認ダイアログあり) | Delete |

---

## 3. データ項目

| 項目 | 型 | 備考 |
|---|---|---|
| サービス名 | 文字列 | 必須 |
| 月額料金 | 数値 | 必須 |
| 解約締切日 | 日付 | 必須。直接入力(自動計算はしない) |
| カテゴリ | 固定の選択肢 | 動画配信 / 音楽 / 仕事・学習ツール / クラウドストレージ / ゲーム / フィットネス・健康 / その他 |

---

## 4. 画面構成

| 画面 | 対応するCRUD | 内容 |
|---|---|---|
| 一覧画面 | Read | サブスク一覧(解約締切日が近い順)+ 月額合計(全体)+ 各行に編集・削除ボタン |
| 登録画面 | Create | サービス名・月額・解約締切日・カテゴリの入力フォーム |
| 編集画面 | Update | 登録画面と同じ項目、既存値が入った状態 |
| (一覧画面内) | Delete | 各行の削除ボタン(確認ダイアログ表示) |

---

## 5. 各機能の詳細仕様

- **並び順**: 解約締切日が近い順
- **合計表示**: 全体の合計金額のみ(カテゴリ別小計はv2で検討)
- **削除**: 確認ダイアログを表示してから削除
- **バリデーション**: 必須項目の未入力・エラーをチェック
- **カテゴリ選択UI**: ボタン(タグ)選択式
